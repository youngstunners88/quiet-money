| Podcastfy (souzatharsis/podcastfy) | **park** | script | Apache-2.0. Turns text, PDFs, websites, YouTube or a topic into a two-voice conversation (short 2-5 minutes or long 30+), with 100+ LLMs for the transcript and OpenAI, Google, ElevenLabs or Microsoft Edge voices. We already hold every part it wraps: Opus 5.5 on OpenRouter writes, Edge and ElevenLabs speak, ffmpeg mixes. The one thing we lack is the conversation format itself. It is a pip package with a pinned-nothing install and a Python 3.11 floor, which is more dependency than the idea needs. | The format, rebuilt in our own code: a two-host dialogue script (host and sceptic, one voice each, Edge voices free) written by Opus from a research brief, rendered with the existing captions as a 'Quiet Money Talks' format for long-form and for 60-second Shorts. | Local Deep Research (LearningCircuit/local-deep-research) | **park** | ideate | MIT. A research assistant that runs its own agent loop with an LLM and search engines and returns cited reports; the README says it needs Ollama (or any OpenAI-compatible endpoint) plus SearXNG, ships as Docker or pip, and makes no telemetry calls. It does not save us money: our research and fact sheets cost a few cents of Opus per video, a local model needs a GPU this container lacks, and a hosted model would cost the same tokens the engine already spends. It adds a service to run. Flags: MED unpinned-run, LOW telemetry (the README says none). | Two ideas. (1) The `search` tool returns raw results from free engines with no LLM call, which is the cheap way to fact-check or watch topics: our engine can call Wikipedia, Wikinews, The Guardian and the Wayback Machine directly for the same effect. (2) A research library that accumulates sources, which our channel/research briefs already do by hand. |
| OpenCreator, formerly KrillinAI (krillinai/OpenCreator) | **park** | render | Apache-2.0. A desktop and web workspace built on Codex CLI, with ten creator tools (video translation to 101 languages, downloader, thumbnails, image and video generation, article, script, stick figure animation, dubbing). It needs a ChatGPT or Codex sign-in, its own account and credits through open-creator.ai, and paid image, video and voice services, so it is a second agent and a second bill beside our headless engine, not something to fork into it. The downloader pulls videos from other platforms, which stays out of scope for us. Skills text and templates were not read. | Three lanes to rebuild in our own code. (1) Stick figure animation: our comics already draw consistent stick figures as SVG, so a comic can become a 15-30 second animated Short (panel reveal, text typed, voice) with HyperFrames and ffmpeg at no per-video cost. (2) Video translation and dubbing: the same Shorts in Spanish and Portuguese with Edge voices and translated captions, a reach lever with no new model. (3) Versioning every revision instead of overwriting, for scripts. The repo's skills/ folder (subtitle, tts, render, cover) should be read once, text only, before copying any wording. |
