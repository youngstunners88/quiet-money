# Changelog

## 0.1.0
- First release. 18 MCP tools for Android (adb) and iPhone (WebDriverAgent).
- Safety: confirmation gate, read-only and dry-run modes, device/path allowlists, shell allowlist, JSONL audit log.
- CLI: `serve`, `doctor`, `list-devices`, `init`.
- Tests against a simulated adb, a mocked WebDriverAgent, and a real stdio MCP session.
