# Money Reset autoresponder

Eight emails (a welcome and days 1-7), generated by `python -m faceless autoresponder` with every number computed.

## To turn it on (owner)
1. Pick an email service with a free tier (MailerLite, Kit, Beehiiv, Buttondown all accept pasted emails or an import).
2. Add your real postal address and the service's unsubscribe link in the footer merge tags. The law requires both; the service may supply them for you.
3. Paste each email, set the delays in the file names (welcome at signup, then day 1 to day 7 at one day apart).
4. Point the 'link in bio' signup form at the sequence.
5. Replies go to the sending mailbox: use one you actually read.

Merge tags differ per service: replace `{{postal_address}}` and `{{unsubscribe_url}}` with the service's own.
Set `[newsletter] planner_url` in studio.toml after the planner is live and day 7 will mention it.
